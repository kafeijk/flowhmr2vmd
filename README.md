# FlowHMR2VMD

> **本项目已停止开发。**

将FlowHMR生成的动作数据转换为VMD格式，并将关键帧注册到当前选中模型的骨骼上。

## 依赖

- Blender 3.2 或更高版本。
- MMD Tools 插件。
- 含 numpy + scipy + torch 的 Python 3 环境（通常位于动补软件文件夹中）。
